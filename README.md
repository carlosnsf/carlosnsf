<details>
<summary><b>🗂️ Diário de classe: como esses sistemas nascem</b></summary>
<br>

1. **Alguém reclama de uma planilha.** Geralmente na segunda-feira.
2. **Sento com quem usa.** Mapeio o processo de verdade, não o que está no papel.
3. **Protótipo rápido.** Uma tela funcionando vale mais que dez reuniões.
4. **Produção com usuários reais.** Ajustes em ciclos curtos, com feedback de quem opera.
5. **Documentação e treinamento.** Sistema que ninguém sabe usar vira planilha de novo.

</details>
